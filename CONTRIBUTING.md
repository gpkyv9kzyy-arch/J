# Contributing to Gojo Limitless

Thanks for considering contributing! We want this theme to be the strongest.

## How to Contribute
1.  Fork the repository.
2.  Create a branch (`git checkout -b feature/cool-update`).
3.  Make your changes.
4.  Open a Pull Request.

## Rules
- Keep the Six Eyes aesthetic (Neon Blue/Cyan).
- No distracting colors.
- Be Limitless.
